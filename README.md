Comer entre Montañas es una aplicación web full stack que promueve el turismo gastronómico en Mendoza, conectando turistas y locales con restaurantes en zonas montañosas.
 Cuenta con un frontend en React y Material UI, y un backend en NestJS con PostgreSQL y TypeORM.
 Permite gestionar usuarios, restaurantes, menús, bebidas, promociones, eventos, reseñas y reservas.
 Incluye autenticación JWT, carga de imágenes, y está diseñada con arquitectura modular, lista para escalar y enfocada en brindar una excelente experiencia al usuario.
